#  MyStore - Application Full-Stack MongoDB

Application de gestion de produits full-stack avec MongoDB, Express et frontend moderne.

##  Fonctionnalités

-  CRUD complet (Create, Read, Update, Delete)
-  Interface utilisateur moderne avec Bootstrap 5
-  Connexion MongoDB avec Mongoose
-  API RESTful complète
-  Validation des données
-  Messages d'alerte en temps réel
-  Design responsive
